## 5. Technical Recommendations

Aligned with a site like the reference (WordPress-style marketing site):

| Option | Notes |
|--------|--------|
| **Static site** | HTML + CSS + JS, or Astro/Next.js — fast, cheap hosting |
| **WordPress** | Similar to reference; easy forms (WPForms), blogs, project pages |
| **Hostinger / Netlify / Vercel** | Good for static or Jamstack |

**Must-have features:**

- Mobile-responsive layout  
- Click-to-call phone on mobile  
- WhatsApp floating button  
- Contact form with spam protection  
- Google Maps embed on Contact  
- SSL (HTTPS)  
- Basic analytics (Google Analytics or Plausible)
